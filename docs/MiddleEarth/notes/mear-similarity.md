# MEAR similarity report

Generated by `tools/middleearth/mear_similarity.py` (re-run it after edition changes; the recommendations below are hand-written in the sibling section). Each MEAR card is scored against all 823 distinct cards of LTR/LTC/PLTC/HOB/HOC (basic lands excluded) on Oracle text (own name replaced by CARDNAME, reminder text dropped; mean of difflib ratio and token Jaccard), mana value, colours, card type, P/T and keyword set. The closest pool card is shown when it passes a tier threshold.

- **Tier 1**: same frame (type and colours) and near-identical text (at least 97% text similarity), mana value within 1 and P/T within 1: functionally identical or strictly better/worse.
- **Tier 2**: very similar (text a hand-reviewed pair or same-keyword body, or at least 68% text similarity with the same type): a different card, but it plays the same role.

Counts: **11 tier 1**, **15 tier 2** (of 233 MEAR cards checked).
